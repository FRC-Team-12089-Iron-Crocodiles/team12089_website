**FONTS**

They are here. Keep them here. 

When following design rules it is best to use 3 or less fonts to keep the pages consistent to each other. 
If more are needed specific places it is okay but try to keep the number of fonts to a minimum and try to use the fonts we already have


**NAMING**

When naming fonts try to name them either what they are used for, or the name of the font if it is rarely used.
For example we used a font and named it body as that is what most of the text will be using.
