**NAMING**

When naming images try to be as descriptive as possible while keeping the name short. 
An example would be to use TeamAroundTable.jpg for an image of the team when they are around the table instead of just team.jpg.

When naming site images like the logo name them what they are, they dont need to be as descriptive.
for example use logo-small.jpg for a small version of the logo.
